О продукте и лицензировании
iBatyr APM 0.5.0-rc1 — оболочка мониторинга и AI-анализа. iBatyr APM agent — фирменный пакет агента на базе Apache SkyWalking Java Agent.
По окончании лицензии AI-анализ отключается. Метрики, трассировки и экспорт остаются доступны. Агент и приложения клиента не останавливаются.
Продукт использует Apache SkyWalking (Apache License 2.0). Он не является выпуском Apache Software Foundation. Сведения о сторонних компонентах входят в дистрибутив.
Текущий выпуск поддерживает offline-лицензии на AI-анализ. Тарифы не включают технический учёт числа агентов, SSO или SLA.
