Вопрос и область анализа

Если экземпляр не выбран, используется первый экземпляр сервиса за период; его имя будет указано в отчёте. Другие JVM не объединяются. Для выбранного профиля передаются агрегаты и время наблюдений, без имён хостов и сырых логов. Вопрос передаётся как введён. Каждый клик может расходовать токены; Live не запускает ИИ автоматически.

    Выберите, где работает ИИ

    Поддерживается Chat Completions в формате OpenAI-compatible. Нативные API Anthropic и Gemini требуют совместимого шлюза.

    Для GPT-4o mini через api.openai.com автоматический режим включает строгую схему. Другие API: выберите поддерживаемый формат. Проверка подключения проверяет доступ к модели; формирование отчёта проверяется при анализе.

    Проверка отправляет короткий запрос «Reply with OK» и может расходовать токены. При смене Base URL введите ключ заново.

    О продукте и лицензировании
    iBatyr APM 0.5.0-rc1 — оболочка мониторинга и AI-анализа. iBatyr APM agent — фирменный пакет агента на базе Apache SkyWalking Java Agent.
    По окончании лицензии AI-анализ отключается. Метрики, трассировки и экспорт остаются доступны. Агент и приложения клиента не останавливаются.
    Продукт использует Apache SkyWalking (Apache License 2.0). Он не является выпуском Apache Software Foundation. Сведения о сторонних компонентах входят в дистрибутив.
    Текущий выпуск поддерживает offline-лицензии на AI-анализ. Тарифы не включают технический учёт числа агентов, SSO или SLA.
