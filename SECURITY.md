# Security

Не публикуйте ключи, лицензии, сырой SQL и production traces в public Issues.
Перед продажей задайте закрытый канал сообщений об уязвимостях и ответственное лицо.
Список известных границ RC: docs/VALIDATION.md и docs/OPERATIONS.md.
Внешний LLM получает данные только после preview/подтверждения; это не замена
политике обработки данных клиента. Оболочка по умолчанию слушает loopback.
