iBatyr APM 0.5.0-rc1 — сведения о составе

Source-пакет содержит собственную оболочку, установщики, инструменты издателя,
тесты и документацию. Клиентский shell-пакет исключает инструменты издателя.

Server-пакет, собранный с --with-vendor, включает неизменённый официальный архив
Apache SkyWalking OAP 10.1.0. Agent-пакет включает неизменённый официальный архив
Apache SkyWalking Java Agent 9.3.0. URL, версии и SHA-512 находятся в versions.json.
В online-варианте эти архивы загружаются установщиком и проверяются по SHA-512.
Хранилище Elasticsearch, Java runtime и веса LLM не включены.

Apache SkyWalking и Apache SkyWalking Java Agent: Apache License 2.0.
https://www.apache.org/licenses/LICENSE-2.0
Полные оригинальные LICENSE/NOTICE и лицензии зависимостей сохраняются
в каждом upstream-архиве и после распаковки. Внутренние JAR и исходные
конфигурационные файлы upstream не редактируются; параметры задаются через
отдельные EnvironmentFile и JVM options. Дополнительные установщики/launcher
относятся к iBatyr. Продукт не является официальным выпуском ASF.

Python-зависимости устанавливаются отдельно через pip. Перед распространением
готового окружения требуется получить фактические LICENSE/NOTICE всех
зафиксированных версий и составить полный SBOM.
Основные зависимости: FastAPI, Starlette, Pydantic, Uvicorn, HTTPX, sqlglot,
cryptography, cffi и транзитивные зависимости.
Это описание состава, не полный аудит лицензий поставляемого окружения.

Коммерческая лицензия относится к AI-анализу оболочки. Она не отменяет права
на оригинальные Apache-компоненты и отдельно лицензированные зависимости.
